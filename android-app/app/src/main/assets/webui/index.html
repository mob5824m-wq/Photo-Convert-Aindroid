Pixel 1–5 Hardware Setup Guide

How the Native Android APK & Google Photos Unlimited Backup work together.

1
Install PixelPhotoNAS.apk on your Pixel 1–5

Supports Pixel / Pixel XL (Android 8–10) through Pixel 2, 3, 3a, 4, 4a, 4a 5G, and Pixel 5 (Android 11–14). Grant All Files Access & Notification permission on first launch.

2
Why .nomedia on Folder 1 + DCIM/PixelNAS on Folder 2 matters

Folder 1 (/storage/emulated/0/PixelNAS/Incoming) automatically contains a .nomedia guard so Google Photos ignores raw 50MB uploads. Once shrunk to ≤16MP & 1080p, files move into Folder 2 (/storage/emulated/0/DCIM/PixelNAS), trigger MediaScannerConnection, and high-res originals are deleted.

3
Enable Backup on PixelNAS in Google Photos

Open Google Photos → Collections / Library → Photos on device → PixelNAS and turn Backup ON. On Pixel 1 select Original Quality; on Pixel 2–5 select Storage Saver for unlimited zero-quota backups!

4
24/7 Closet Server Protection

Includes BOOT_COMPLETED auto-restart after power loss, Wi-Fi lock, 4GB RAM OOM-safe sub-sampled decoding for 200MP photos, hardware MediaCodec 1080p encoding, and 41°C Battery Thermal Guard.
