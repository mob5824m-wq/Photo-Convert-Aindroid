2-APK Household Setup Guide

How the Closet Pixel 1–5 NAS APK + Household Samba Client APK work together.

1
APK #1 (PixelPhotoNAS.apk) → Closet Pixel 1–5 Server

Runs the 24/7 Samba (SMB2), Web UI, WebDAV, and FTP server plus hardware Storage Saver conversion into DCIM/PixelNAS for unlimited Google Photos backup.

2
APK #2 (PixelPhotoNAS-Household.apk) → Every Family Phone

Lightweight Samba/SMB2/3 Android client for every household phone: connects directly to \\<NAS>\PixelNAS (port 445 or 4445), uploads batches with atomic rename, browses shares, runs Wi-Fi auto-backup, and adds the Home Screen Widget + Share Sheet target.

3
Enable Backup on PixelNAS in Google Photos

Open Google Photos → Collections / Library → Photos on device → PixelNAS (plus any custom album folders like Family) and turn Backup ON.

4
